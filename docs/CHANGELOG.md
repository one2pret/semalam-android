# Changelog

## 0.1.0-alpha01 — 2026-11-02

- Created native Kotlin/Compose proof-of-concept source for Semalam.
- Foreground microphone recording service and user-initiated Start/Stop.
- Generic sound-activity detector, 12-second room calibration, local WAV snippets.
- JSON session timeline, manual labels, playback, deletion, and bedtime reminder.
- No snore/voice classification and no medical claims.
- Synthetic audio algorithm tests added.
- GitHub Actions **workflow created in source**, no remote CI run or verified APK yet.
